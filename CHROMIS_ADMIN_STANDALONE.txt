🚀 CÓMO USAR
════════════════════════════════════════════════════════════════════════════

OPCIÓN 1: COMPILAR Y EJECUTAR (RECOMENDADO)
───────────────────────────────────────────

1. Abre tu terminal/CMD en:
   C:\xampp\htdocs\chromispos\ChromisPOS

2. Ejecuta:
   compile_standalone.bat

3. Espera a que termule la compilación

4. Ejecuta la aplicación:
   java -jar ChromisAdmin.jar

   O simplemente haz doble clic en: ChromisAdmin.jar


OPCIÓN 2: EJECUTAR DIRECTAMENTE (si ya está compilado)
──────────────────────────────────────────────────────

En terminal (en el directorio ChromisPOS):
   java -jar ChromisAdmin.jar

O haz doble clic en: ChromisAdmin.jar
