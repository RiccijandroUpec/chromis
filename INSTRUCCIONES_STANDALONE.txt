OPCIÓN 1: COMPILAR Y EJECUTAR (RECOMENDADO)
────────────────────────────────────────

PASO 1: Abre CMD (Símbolo del Sistema)
  • Presiona: Windows + R
  • Escribe: cmd
  • Presiona: Enter

PASO 2: Ve a la carpeta ChromisPOS
  Escribe: cd C:\xampp\htdocs\chromispos\ChromisPOS
  Presiona: Enter

PASO 3: Ejecuta el compilador
  Escribe: compile_standalone.bat
  Presiona: Enter

  → Verás mensajes de compilación
  → Espera a que termine (30-60 segundos)
  → Si dice "OK" al final = ¡Éxito!

PASO 4: Ejecuta la aplicación
  Escribe: java -jar ChromisAdmin.jar
  Presiona: Enter

  → ¡La aplicación se abre en una ventana!
  → TODO en una sola aplicación
  → Nada disperso


OPCIÓN 2: VER PRIMERO EN NAVEGADOR
──────────────────────────────────

ANTES de compilar, puedes ver cómo se verá:

  Abre: C:\xampp\htdocs\chromispos\ChromisPOS\chromis_admin_preview.html

  → Ves la interfaz completa
  → Tabs funcionando
  → Totalmente interactivo
  → Así se verá cuando ejecutes el JAR


OPCIÓN 3: EJECUTAR DIRECTAMENTE EL JAR

Si ya compilaste y tienes ChromisAdmin.jar:

MÉTODO A:

MÉTODO B (Terminal):

  • ¡Se abre!

💡 PREGUNTAS FRECUENTES
════════════════════════════════════════════════════════════════════════════

P: ¿Necesito desinstalar ChromisPOS?
R: No. Esta aplicación es INDEPENDIENTE. ChromisPOS sigue igual.

P: ¿Dónde guarda los datos?
R: En la base de datos MySQL (chromisnewtest) si la conectas.

P: ¿Puedo usarla sin MySQL?
R: Sí, pero sin conexión a BD. La interfaz se ve igual.

P: ¿Se actualiza automáticamente?
R: No. Compilas una vez y tienes el JAR.

P: ¿Cuánta memoria usa?
R: ~100-150 MB en RAM cuando está abierta.

P: ¿Compatible con el POS?
R: Es independiente. Complementa sin interferir.

P: ¿Puedo personalizarlo?
R: Sí. El código fuente está en ChromisAdminApp.java


🔧 SI OCURREN PROBLEMAS
════════════════════════════════════════════════════════════════════════════

PROBLEMA: "No se encuentra Java"
SOLUCIÓN:
  • Verifica que Eclipse Adoptium está instalado
  • Ruta esperada: C:\Program Files\Eclipse Adoptium\jdk-11.0.29.7-hotspot
  • Si no: descarga de https://adoptium.net/

PROBLEMA: "Compilation failed"
SOLUCIÓN:
  • Verifica que chromisAdminApp.java no tiene errores de sintaxis
  • Intenta compilar manualmente:
    javac src-pos\uk\chromis\pos\panels\ChromisAdminApp.java

PROBLEMA: "JAR no se abre"
SOLUCIÓN:
  • Intenta desde terminal:
    java -jar ChromisAdmin.jar
  • Verifica que el JAR existe en el directorio
