🎯 PARA EJECUTAR (MUY SIMPLE):
════════════════════════════════════════════════════════════════════════════

PASO 1: Compilar
─────────────────
Doble clic en:
  C:\xampp\htdocs\chromispos\ChromisPOS\COMPILAR_DESKTOP.bat

O en terminal:
  cd C:\xampp\htdocs\chromispos\ChromisPOS
  COMPILAR_DESKTOP.bat

Espera 30-60 segundos... verás mensajes de compilación.

Resultado: Se crea ChromisAdmin.jar


PASO 2: Ejecutar la Aplicación de Escritorio
──────────────────────────────────────────────

OPCIÓN A (Más fácil):
  • Doble clic en: ChromisAdmin.jar
  • ¡Se abre la ventana!

OPCIÓN B (Terminal):
  java -jar ChromisAdmin.jar

OPCIÓN C (Script automático):
  Doble clic en: RUN.bat
  (Compila y ejecuta automáticamente)
