OPCIÓN 1 - MÁS FÁCIL (AUTOMÁTICO):
───────────────────────────────────

Abre CMD aquí: C:\xampp\htdocs\chromispos\ChromisPOS\

Y ejecuta:

    EJECUTAR_AHORA.bat

O doble clic en: EJECUTAR_AHORA.bat

Esto compila y abre la aplicación automáticamente.


OPCIÓN 2 - PASO A PASO:
─────────────────────

En CMD (abierto en C:\xampp\htdocs\chromispos\ChromisPOS\):

1. Compilar:
   COMPILAR_DESKTOP.bat

2. Ejecutar:
   java -jar ChromisAdmin.jar


OPCIÓN 3 - SI YA COMPILÓ ANTES:
───────────────────────────────

Solo ejecuta:
   java -jar ChromisAdmin.jar

O doble clic en: ChromisAdmin.jar
