🚀 CÓMO EJECUTAR (SIMPLE)
════════════════════════════════════════════════════════════════════════════

PASO 1: Abre CMD
  Windows + R → cmd → Enter

PASO 2: Ve a la carpeta
  cd C:\xampp\htdocs\chromispos\ChromisPOS

PASO 3: Compila
  compile_standalone.bat

PASO 4: Ejecuta
  java -jar ChromisAdmin.jar

LISTO: ¡La aplicación se abre con TODA la configuración centralizada!
