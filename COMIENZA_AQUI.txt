🎯 PASOS PARA EJECUTAR (MUY SIMPLE):
════════════════════════════════════════════════════════════════════════════════

PASO 1: COMPILAR LA APLICACIÓN
───────────────────────────────

Ubica: C:\xampp\htdocs\chromispos\ChromisPOS\

Doble clic en: COMPILAR_DESKTOP.bat

(O en terminal: COMPILAR_DESKTOP.bat)

Espera: 30-60 segundos

Resultado: Se crea ChromisAdmin.jar


PASO 2: EJECUTAR LA APLICACIÓN DE ESCRITORIO
──────────────────────────────────────────────

Ahora que tienes ChromisAdmin.jar creado:

OPCIÓN A (Más fácil):
  Doble clic en: ChromisAdmin.jar
  
  ¡Se abre una ventana de aplicación!

OPCIÓN B (Terminal):
  java -jar ChromisAdmin.jar
  
  ¡Se abre una ventana de aplicación!

OPCIÓN C (Automático):
  Doble clic en: RUN.bat
  
  (Compila y ejecuta automáticamente)

🚀 FLUJO RÁPIDO:
════════════════════════════════════════════════════════════════════════════════

1. cd C:\xampp\htdocs\chromispos\ChromisPOS

2. Doble clic en COMPILAR_DESKTOP.bat
   (o en terminal: COMPILAR_DESKTOP.bat)
   
3. Espera a que diga: "✅ COMPILACIÓN COMPLETADA EXITOSAMENTE"

4. Doble clic en ChromisAdmin.jar
   (O: java -jar ChromisAdmin.jar)

5. ¡Se abre la ventana de la aplicación!

6. Ves 6 tabs con 49 opciones, todo centralizado
